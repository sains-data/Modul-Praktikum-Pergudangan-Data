# Data Praktikum

- `raw/`: data sumber yang tidak diubah langsung.
- `processed/`: hasil pembersihan atau transformasi yang dapat dibuat ulang.
- `sample/`: sampel kecil yang aman disimpan dalam repository.

Dokumentasikan asal data, lisensi, tanggal pengambilan, checksum, dan perintah
unduh pada berkas ini saat dataset sudah dipilih. Jangan menyimpan data sensitif
atau kredensial.
