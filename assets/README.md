# Assets

Simpan aset visual dengan susunan berikut ketika mulai digunakan:

```text
assets/
├── bersama/       # logo, ikon, atau elemen yang dipakai lintas modul
└── modul-XX/      # diagram dan tangkapan layar khusus modul
```

Gunakan nama berkas deskriptif, huruf kecil, dan tanda hubung. Utamakan PDF/SVG
untuk diagram dan PNG/JPEG untuk tangkapan layar atau foto.
